# CliqueObras Premium v2.3

- Interface mais sólida: removidos halos, brilhos e sombras coloridas de ícones e ações primárias.
- Removida a opção de apagar todos os dados do sistema.
- Usuários sem vínculo ativo com uma organização são desconectados e recebem uma mensagem de acesso indisponível, sem tela de falha.
- Removido o perfil duplicado do canto superior direito.
- O perfil superior esquerdo mostra o nome do usuário e, abaixo, o nome da organização.
- Gastos futuros respeitam o projeto selecionado no filtro global.
